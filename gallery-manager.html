PicturePlush Galerie-Manager

Lokales Hilfswerkzeug für GitHub Desktop. Die Seite lädt nichts ins Internet hoch. Du wählst Bilder aus, ergänzt Beschreibungen und lädst anschließend eine neue gallery-data.js herunter.

1. Bilder auswählen

Kopiere dieselben Bilddateien danach nach assets/img/gallery/custom/. Am besten Dateinamen ohne Umlaute und Leerzeichen verwenden.

3. Bibliothek erzeugen



So kommt es auf GitHub
  1. Lege die ausgewählten Bilder in assets/img/gallery/custom/.
  2. Ersetze assets/js/gallery-data.js durch die hier heruntergeladene Datei.
  3. GitHub Desktop zeigt die Änderungen automatisch an.
  4. Commit to main und danach Push origin.
Hinweis: Eine statische GitHub-Pages-Seite kann Dateien nicht selbst dauerhaft in dein Repository schreiben. Dafür wäre später ein echtes Admin-Backend oder die GitHub-API mit sicherer Authentifizierung nötig.
